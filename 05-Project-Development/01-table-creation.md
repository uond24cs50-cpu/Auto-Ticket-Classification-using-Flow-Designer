# Table Creation

## Objective

Create a custom table to store IT ticket records.

## Navigation

1. Open All menus.
2. Search for Tables.
3. Under System Definition, select Tables.
4. Click the New button.

## Table Configuration

### Label

Incident WorkFlow

### Create Module

Uncheck the Create module option.

### Save

Save the form.

## Auto Number Configuration

1. Open the Controls section.
2. Enable the Auto Number checkbox.
3. Save the form again.

## Result

The custom Incident WorkFlow table is created to store the IT ticket records with automatically generated ticket numbers.
