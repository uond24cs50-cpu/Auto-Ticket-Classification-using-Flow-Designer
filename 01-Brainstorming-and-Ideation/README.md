# Brainstorming & Ideation

## Project Title
Auto Ticket Classification using Flow Designer

## Problem
The school IT helpdesk receives multiple incident requests such as Wi-Fi issues, projector failures, password problems, and slow computers.

## Proposed Solution
Automate ticket classification using ServiceNow Flow Designer by analyzing keywords in the ticket description.

## Objective
- Automatically classify incidents.
- Reduce manual effort.
- Improve ticket routing efficiency.
- Implement a no-code solution.
