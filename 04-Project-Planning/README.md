# Project Planning

## Project Title
Auto Ticket Classification using Flow Designer

## Project Plan

The project will be completed in the following steps:

1. Create a new Update Set.
2. Create the Incident Workflow custom table.
3. Create the required fields.
4. Configure Category and Subcategory choices.
5. Implement dependency between Category and Subcategory.
6. Create the Flow Designer flow.
7. Configure automatic ticket classification.
8. Configure email notification.
9. Test the project with different ticket scenarios.
10. Complete the Update Set and prepare the project for deployment.

## Flow Classification Plan

WiFi or Network → Network → Wi-Fi

Projector → Hardware → Projector

Password or Login → Access → Forgot Password

Slow or Hanging → Performance → Slow Computer

## Expected Outcome

The system should automatically classify newly created IT tickets and send an email notification to the caller.
