# Test Cases

| Test Case | Short Description | Expected Category | Expected Subcategory | Expected Email |
|---|---|---|---|---|
| TC01 | WiFi not working in library | Network | Wi-Fi | Yes |
| TC02 | Projector not turning on | Hardware | Projector | Yes |
| TC03 | Forgot password | Access | Forgot Password | Yes |
| TC04 | Computer is slow | Performance | Slow Computer | Yes |

## Validation

Each test case should be executed by creating a new ticket and checking whether the Flow Designer assigns the expected Category and Subcategory.

The email notification should also be verified for the caller.
