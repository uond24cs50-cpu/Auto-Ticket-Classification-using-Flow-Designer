# Requirement Analysis

## Project Title
Auto Ticket Classification using Flow Designer

## Business Requirements

The system must:

1. Automatically classify IT tickets based on the issue description.
2. Assign Category and Subcategory without manual intervention.
3. Support dependent choice logic between Category and Subcategory.
4. Send an automated email notification to the caller upon ticket creation.
5. Store ticket information in a structured and standardized format.
6. Ensure easy maintenance and future scalability.

## Problem Analysis

The school IT helpdesk receives support requests related to network connectivity, hardware failures, account access problems, and system performance issues.

Currently, IT staff manually review each ticket and select the appropriate category and subcategory. This process is time-consuming and error-prone.

## Proposed Solution

Use ServiceNow Flow Designer to automatically classify tickets based on keywords in the Short Description field.
