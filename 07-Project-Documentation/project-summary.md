# Project Summary

## Project

Auto Ticket Classification using Flow Designer

## Purpose

To automatically classify school IT support tickets based on the issue description.

## Main Components

- Custom ticket table
- Category field
- Subcategory field
- Category/Subcategory dependency
- Flow Designer automation
- Email notification

## Classification

WiFi → Network → Wi-Fi

Projector → Hardware → Projector

Password / Login → Access → Forgot Password

Slow / Hanging → Performance → Slow Computer

## Outcome

The completed solution provides an automated process for ticket classification and caller notification.
